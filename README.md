# Shree Swami Samarth Events

Luxury Event Management & Décor website built with **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS v4**, and **Lucide Icons**.

---

## ✨ Features

- **Hero Showcase**: Arched frame slider with smooth transitions and quick inquiry triggers
- **Services Section**: Comprehensive packages for Birthdays, Baby Showers, Weddings, Festive Decor, and Corporate Events
- **Portfolio / Bento Gallery**: Filterable case-study showcase with high-res modal previews
- **About Us**: Brand story, core pillars, and company milestones
- **Client Testimonials**: Verified reviews and interactive review submission modal
- **Contact & Location**: Interactive Google Maps embed, direct WhatsApp routing, and inquiry form
- **WhatsApp Floating Button**: Quick-access event planning trigger on all screen sizes (Desktop, Tablet, Mobile)
- **Responsive & Accessible**: Optimized for mobile and desktop viewports with smooth scroll animations

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🛠️ Build & Production

```bash
# Production build
npm run build

# Start production server
npm run start
```

## 📁 Project Structure

```
├── app/                  # Next.js App Router (layout, page, globals.css)
├── components/           # Reusable UI components & modals
├── data/                 # Events, services, and business contact data
├── hooks/                # Custom React hooks (scroll reveal, body scroll lock)
├── lib/                  # Utility functions (cn helper)
├── public/               # Static assets (images, favicon)
├── next.config.mjs       # Next.js configuration
├── postcss.config.mjs    # PostCSS Tailwind plugin config
├── tsconfig.json         # TypeScript configuration
└── package.json          # Project metadata and dependencies
```
